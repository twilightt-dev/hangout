# 附近店铺 GEO 实现代码导读

## 学到的内容

- 用户定位是一次查询输入，不是服务端持续跟踪。
- Redis GEO 只保存位置索引；查询命中后仍需批量回源店铺详情。
- `GEOSEARCH` 的参照点是用户 `longitude`、`latitude`，半径固定 5 km，按距离升序最多取 50 条。
- 店铺新增、更新、类型迁移和删除都要同步对应的 `shop:geo:{typeId}`。
- 定位失败时前端降级为人气排序，不使用固定坐标伪造“附近”。

## 关键代码路径

`ShopListView.loadNext` → `ShopServiceImpl.queryByDistance` → `GeoOperations.search` → `listByIds` → `ShopCard`。
