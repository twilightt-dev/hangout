# Triage 标签

工程技能使用五种规范化的 triage 角色。本文件将这些角色映射到本仓库 issue tracker 使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不计划处理 |

技能提到某个角色时，使用表中对应的本仓库标签字符串。若标签词汇发生变化，只修改右侧“本仓库标签”列。
